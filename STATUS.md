# Contexto status

Updated 2026-10-16 05:05Z by intake.lead. Decisions taken and still open, with reasons:
`docs/DECISIONS.md`. Every number below is measured unless marked otherwise.

## Where the project is

Contexto keeps very long Claude Code (and Codex) sessions under a fixed context bound so the CLI
never compacts, by putting a local proxy between the CLI and the model API. The owner's bar (D2):
compaction never fires, and accuracy equals full context.

- M0 study: complete. Recommendation `docs/research/M0-recommendation.md`.
- M2 build: the product is implemented on main and runs end to end through
  `contexto run claude ...`. Contract: `docs/milestones/M2-contexto-proxy.md`.
- Acceptance: the bound holds; accuracy does NOT yet meet D2. Work to close the gap is in
  progress (below). No release has been cut.

## What exists on main

- `contexto run claude|codex`: launcher with explicit `--settings` and `--mcp-config` (D16, D22).
- Local proxy on 127.0.0.1: SSE relay, upstream resolution, count_tokens, compressed-body decode or
  415 (rule 15), stream hold until the per-turn room is published. The one safe retry before the
  request body is fully sent (rule 8) is specified but not yet in the code (A10, in progress).
- Rewrite engine (rules 1 to 14): turn-boundary rotation with thinking stripped, carried system
  context, window sized after fixed overhead with a minimal-window fallback, append-only degraded
  mode on store failure, Responses (Codex) dialect.
- Store: hash-chained ledger (pins, decisions, obligations), keyed immutable pages with
  quarantine, index stubs listing keys and paths only (never values), per-turn recall budget.
- MCP tools: `contexto_recall`, `contexto_search`, `contexto_pin`, `contexto_close`,
  `contexto_state`.
- CI on every PR and every push to main; release workflow (tag-only, off until enabled, D14).
- Tests: 850+ passing on main.

## Open decisions (details in DECISIONS.md)

- O3 (intake): the working-window bound, provisional at 150,000; acceptance reruns inform it.

  thinking traced to the proxy spreading requests across identities).
- O7 (owner): OpenRig context-usage clock bug (UTC parsed as local time).

## Known limitations

- Subagents share one session's recall room; concurrent ones can overspend it.
- `preamble_first` is unmeasured on Codex.
- Very large single turns can still exceed the bound inside a tool loop (logged `over_bound`).

## Process notes

- Only intake runs in the main checkout; every other seat works in its own worktree. Builders
  check `git diff --stat origin/main...HEAD` before every push (two stale-tree incidents, PRs #49
  and #80, were caught before merge).
- Direct API requests identify honestly and carry no other product's client marker (D23).
- PR approvals are not enforced by GitHub (one shared account); exact-head review by a reviewer
  seat is a team rule. Ruleset `main: require pull request` (id 25202810) is active.
